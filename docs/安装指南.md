# 安装指南

## 1. 环境要求

| 项目 | 要求 |
|---|---|
| Node.js | 22.19+（推荐 22 LTS）或 24.x |
| npm | 10+ |
| 系统 | macOS 12+ / Linux（systemd user）/ Windows 10+ |
| 权限 | 普通用户即可；不需要管理员/root |

安装脚本会自动检查 Node 版本，不满足时直接报错并提示。依赖与编译产物都放在仓库内的 `apps/freellmapi/node_modules` 和 `dist/`，不会写入系统目录。

## 2. 一键安装

### macOS / Linux

```bash
./install.sh                 # 交互式：每步回车用默认值
./install.sh --defaults      # 全默认：3001 / 18899、启用 OFM 与开机自启
```

### Windows

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Defaults
```

脚本依次执行：

1. 检查 Node 版本
2. `cd apps/freellmapi && npm ci`
3. `npm run build:server`
4. `node bootstrap/setup.mjs` 生成配置
5. `node bootstrap/control.mjs install-autostart` 注册开机自启
6. `node bootstrap/control.mjs start` 启动服务
7. `node bootstrap/doctor.mjs` 健康检查

安装结束后，健康检查里「模型列表」和 `my-group` 两项**可能未通过**——这是正常的：新库还没有任何免费渠道。按下一节添加渠道后再检查。

## 3. 配置项说明

生成于 `config/deployment.json`，重新运行 `setup.mjs` 可修改。

| 字段 | 默认值 | 说明 |
|---|---|---|
| `apiPort` | `3001` | 主服务端口 |
| `host` | `127.0.0.1` | 仅本机；改 `0.0.0.0` 可供局域网访问 |
| `ofmEnabled` | `true` | 是否启动免费渠道网关 |
| `ofmPort` | `18899` | OFM 网关端口 |
| `tunnelMode` | `off` | `off` / `quick`（临时地址）/ `named`（固定域名） |
| `autostart` | `true` | 是否注册开机自启 |
| `publicUrl` | 空 | 公网入口，仅用于健康检查 |

`apps/freellmapi/.env` 由向导生成，包含 `PORT`、`HOST`、`DSH_GATEWAY_URL`；不要手动加入 `ENCRYPTION_KEY`，首次启动会自动生成并保存在数据库旁。

## 4. 首次添加免费渠道（必做）

1. OFM 网关启动后，日志会打印：
   `管理页面（10 分钟内一次性登录）：http://127.0.0.1:18899/...`
   在 10 分钟内打开并完成一次性登录。
2. 在管理页查看网关的转发密钥，或查看 `ofm-data/` 里保存的 API Key 文件。
3. 打开 freellmapi 管理页 `http://127.0.0.1:3001`，注册管理员账号（首次启动日志有一次性设置码）。
4. 添加渠道：平台选 `dsh`，Base URL 填 `http://127.0.0.1:18899/v1`，密钥填第 2 步的转发密钥，启用该渠道。
5. 触发一次模型同步（管理页操作即可，服务也会在启动 20 秒后和每 6 小时自动同步）。
6. 创建单入口分组并验证：

```bash
node bootstrap/seed-group.mjs
node bootstrap/doctor.mjs
```

看到 `my-group 实际调用 ✓` 就可以接入客户端了。

## 5. 升级

```bash
git pull
./install.sh --defaults
```

`npm ci` 会重装依赖，`build:server` 会重编译；**数据库、密钥、渠道配置都保留**，不会被覆盖。`setup.mjs` 会重写 `.env`，但默认值不变时无影响；自定义过端口的话重新选一遍即可。

## 6. 卸载

```bash
node bootstrap/control.mjs uninstall-autostart
node bootstrap/control.mjs stop
```

然后删除仓库目录即可。删除前如需保留配置，请备份：

- `apps/freellmapi/server/data/`（数据库 + `.encryption-key`，两者必须成对）
- `ofm-data/`（OFM 账号与渠道状态）
- `config/deployment.json`

只备份数据库、不备份密钥文件，恢复后所有渠道密钥都无法解密。
