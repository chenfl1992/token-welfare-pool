# 工作原理

## 四层架构

```
① 客户端层   WorkBuddy / Codex / Gemini CLI / 其他智能体
                        ↓ OpenAI 兼容 /v1
② 公网入口   可选：Cloudflare 隧道（quick 临时地址 / named 固定域名）
                        ↓
③ 调度层      freellmapi · 3001
              可用性门控 · 智能路由 · 自动签到 · 模型分组 · 模型同步
                        ↓ DSH_GATEWAY_URL
④ 渠道层      OFM 网关 · 18899
              免费渠道账号池 · 429/5xx 自动回退 · 冷却与评分
```

请求从客户端进入 freellmapi，路由层从可用模型里挑一个最优成员，再转发给 OFM 网关；网关负责落到具体免费渠道。签到与同步服务在后台持续维护额度和模型清单。

## 启动时序（换台电脑也能跑的关键）

1. `initDb()` 自动创建 `server/data/` 并执行全部迁移，建好 `settings`、`models` 等表。
2. 自动检查密钥文件，首次启动生成 `.encryption-key`；数据库和密钥文件必须成对存在。
3. 若 `userCount() === 0`，生成一次性设置码并打印到日志，用于首次注册管理员。
4. 生成统一 API Key 写入 `settings.unified_api_key`，客户端用它调用 `/v1`。
5. 启动健康检查、目录同步、冷却探测、模型探测、DSH 签到、DSH 模型同步等后台任务。

所以新机器只要执行安装脚本、添加渠道，不需要手工导入数据库。

## 自动签到

签到服务通过 OFM 网关管理接口调用 `credits.claimAll`，遍历所有已配置的 DSH 渠道逐个领取每日额度。成功后做两件额外的事：

- 清除该渠道当天的限流冷却（领了新额度就该重新可用）
- 触发一次模型同步（新额度常伴随新渠道上线）

调度时间：

| 时机 | 说明 |
|---|---|
| 启动后 30 秒 | 补签；白天开服也能领到 |
| 每天 00:05（本地时间） | 主签到点，额度午夜重置后立刻领取 |
| 每 6 小时 | 当天 00:05 那次失败后的补签机会；当天去重保证实际只签一次 |

日志示例：

```
[dsh-checkin] DSH 网关: claim ok, cleared 13 cooldown(s)
[dsh-checkin] run complete: 1/1 key(s) claimed via http://127.0.0.1:18899/v1
```

## 路由排名

优先级是 **不限流 > 响应快 > 更智能**：

1. 模型先过「可用性门控」：没有 429、不在冷却中的模型整体排在受限组之前。
2. 可用性相同时，用响应速度做二次排序。
3. 再相同才用智能度权重。

一个关键修正：OFM 是**聚合网关**，某一个底层渠道返回 5xx 不代表整个网关挂了。所以路由层让 `dsh` 平台豁免「平台级错误整体跳过」逻辑，避免一次渠道抖动导致所有模型被误判不可用。

## 模型同步

- 启动后 20 秒首次同步，之后每 6 小时一次。
- 从 OFM 网关 `/v1/models` 拉取模型清单，增量注册到数据库。
- 签到成功后额外触发一次同步。

## my-group 单入口

`my-group` 是一组模型的逻辑名，客户端填它作为 model 即可，组内自动挑最快可用成员。

本项目在标准分组之上加了**视觉分流**：

- 请求带图片，且组内有 `supports_vision=1` 的成员 → 保留图片，走视觉模型。
- 请求带图片，但组内全是文本模型 → 服务端剥掉图片转文字兜底，不再报错。
- 纯文本请求 → 走最快的文本模型。

`bootstrap/seed-group.mjs` 会从当前 `/v1/models` 中按名称规则挑选快模型与视觉模型，写入分组并标记视觉能力。渠道变化后可随时重跑覆盖。

## 数据落盘

| 路径 | 内容 | 是否可提交 |
|---|---|---|
| `apps/freellmapi/server/data/freeapi.db` | 渠道密钥、设置、模型状态 | ❌ 含密钥 |
| `apps/freellmapi/server/data/.encryption-key` | 数据库解密密钥 | ❌ 必须与 DB 成对 |
| `ofm-data/` | OFM 账号、渠道状态、转发密钥 | ❌ |
| `config/deployment.json` | 本机端口/自启配置 | ❌ |
| `apps/freellmapi/.env` | 端口与网关地址 | ❌ |
